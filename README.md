# Muhammad Mansoor Satti — Portfolio

Static portfolio for GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Replace project screenshots later

The project images are deliberately marked as placeholders. After permission is granted, replace the relevant SVG files with real screenshots and update the `src` values in `index.html` if using PNG/JPG/WebP filenames.

Suggested real screenshot names:

- `assets/images/projects/ride-with-pals/01.png`
- `assets/images/projects/ride-with-pals/02.png`
- `assets/images/projects/roomply/01.png`
- `assets/images/projects/roomply/02.png`
- `assets/images/projects/oracle/01.png`
- `assets/images/projects/oracle/02.png`
- `assets/images/projects/otakushelf/01.png`
- `assets/images/projects/otakushelf/02.png`

## Existing GitHub Pages files

If the existing `satti201.github.io` repository already contains `app-ads.txt` or a Google verification file, keep those files when copying this portfolio into the repository.
